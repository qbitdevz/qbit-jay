# qbit-jay Cloud Branding

qbit-jay Cloud uses the same identity as the rest of qbit-jay: direction 03, the hexagon-facet jay with an acorn. There is no separate Cloud logo.

| Need | Where |
| --- | --- |
| Name story, assets and where each one is used | [docs/BRAND.md](../BRAND.md) |
| Colours, typography, spacing and radius tokens | [design/system.md](../../design/system.md) |
| Dashboard theme (generated from the tokens) | `internal/qbit/theme`, served at `/dashboard/static/theme.css` |

## Rules

- Use the `qbit-jay-*` assets only. Engram's logos and images are not part of this project (see [TRADEMARKS.md](../../TRADEMARKS.md)).
- Keep clear space of half the isotype height on every side and a minimum isotype size of 32 px.
- Say "qbit-jay Cloud" in titles and copy.
